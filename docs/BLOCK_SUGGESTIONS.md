# 묶음 추천

매크로 편집의 **묶음 추천**을 누르면 현재 매크로의 일반·병렬·중단 액션에서 완전히 동일한 묶음을 찾습니다. 자동 팝업은 띄우지 않습니다.

1. 위 목록에서 추천 후보를 선택합니다.
2. 내용을 확인하고 적용할 위치를 체크합니다. **위치 보기** 또는 위치 더블클릭으로 원래 액션에 이동할 수 있습니다.
3. 이름을 입력하고 **일반 그룹으로 정리** 또는 **하나의 공용 블록으로**를 누릅니다.

- 일반 그룹: 각 위치를 순서대로 모두 실행하는 독립 그룹으로 정리합니다.
- 공용 블록: 선택한 위치들이 하나의 원본을 공유합니다.
- 여러 곳을 적용해도 실행 취소 한 번으로 복구합니다. 매크로 편집 취소 시 변경도 취소됩니다.

특정 부분을 기준으로 찾으려면 같은 분기의 연속 액션을 선택하고 우클릭 → **이 부분과 같은 묶음 찾기**를 사용합니다. 반복 위치가 없는 선택도 일반 그룹으로 정리할 수 있습니다.

자동 추천은 내부 액션을 포함해 2개 이상인 IF·그룹 또는 연속 2~8줄을 대상으로 하며, 큰 묶음부터 보여주고 겹치는 하위 후보는 제외합니다. 선택 검색에는 8줄 제한이 없습니다. 이름·조건·시간·활성 여부까지 동일한 내용만 합칩니다. 조건이 다르더라도 그 내부 액션들만 같으면 내부 묶음이 추천될 수 있습니다.

라벨 이동, 기존 공용 호출, 병렬 실행 설정, 조건 재확인이 포함된 묶음과 우선순위 그룹의 직속 액션은 자동 정리에서 제외합니다. 검토 도중 편집 내용이 바뀌면 **다시 찾기**로 갱신해야 합니다. 다시 찾기는 현재 매크로 전체를 검색합니다.
