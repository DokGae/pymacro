# IF 실행 테스트

기존 IF를 더블클릭하면 액션 설정의 조건 아래에 **IF 실행 테스트**가 표시됩니다.

- **실제 조건 사용**: 원래 조건으로 판단합니다.
- **다음 1회 강제 참**: 해당 IF에 다음으로 도달했을 때 한 번만 참으로 처리합니다. 도달하지 않거나 액션이 비활성이면 소비되지 않습니다.
- **계속 강제 참**: 해당 매크로 실행이 끝나거나 정지할 때까지, 이 IF에 도달할 때마다 참으로 처리합니다.

판정 선택은 임시 실행 설정으로 즉시 적용됩니다. 설정창을 닫아도 유지되며 원본 JSON에는 저장하지 않습니다. 내부의 다른 IF는 각각의 실제 조건을 판단합니다. 정상 종료·정지·파일 전환 시 강제 설정을 해제합니다. 설정 적용으로 대상 IF가 바뀌면 일치하지 않는 테스트 설정도 해제합니다.

## 선택한 IF부터 실행

엔진을 시작하고 활성화한 다음 **이 IF부터 실행**을 누릅니다. 현재 편집 중인 액션 값으로 메인사이클을 한 번 실행합니다. 앞선 액션과 상위 IF의 조건 검사는 건너뛰고, 선택한 IF부터 시작합니다. 이후의 그룹 선택·반복·라벨 이동 규칙은 기존과 같습니다. 내부에 무한 반복이나 되돌아가는 라벨 이동이 있으면 **중지 / 강제 해제**로 끝낼 수 있습니다.

이 버튼은 메인사이클의 IF에서 사용할 수 있습니다. 다른 병렬 작업은 함께 시작하지 않습니다. 병렬·종료 액션의 IF도 강제 판정 선택은 사용할 수 있으며, 평소 실행 흐름에서 해당 IF에 도달할 때 적용됩니다.

실제 키·마우스 입력과 액션 동작이 발생합니다. 설정창의 실행 내역에는 최근 100개의 실행·판정 기록을 표시하고, 액션 목록에는 강제 설정과 현재 실행 위치를 표시합니다. 빠르게 끝나는 액션은 실행 내역으로 확인할 수 있습니다.

**중지 / 강제 해제**는 해당 매크로를 정지하고 임시 강제 설정을 해제합니다. 선택 위치 테스트를 실행한 매크로 편집창을 닫을 때도 진행 중인 테스트를 정지합니다.

새 액션이나 새 매크로는 먼저 추가·적용한 다음 IF 설정창을 다시 열어 테스트할 수 있습니다.
