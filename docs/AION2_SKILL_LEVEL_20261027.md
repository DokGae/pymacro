# 아이온2 스킬 레벨 조건

조건 편집 → 아이온2 전용 → 스킬 레벨 확인에서 직업·스킬을 선택하고 비교 방식과 기준 레벨을 정한다. 예: 절단의 맹타 ≥ 10레벨.

일반 스킬·패시브·스티그마 337개를 모니터의 보유 스킬 카탈로그와 동일하게 제공한다. 일반 스킬은 `내.스킬.<공백 없는 이름>`, 스티그마는 `내.스티그마.<공백 없는 이름>`의 정수 레벨을 읽는다. 모니터 설정 → 스킬관리에서 해당 스킬의 레벨 전송을 체크해야 한다. 퀵슬롯 등록과 무관하며 별도 전체 전송 설정은 없다. 소스 ID와 포트는 기존 아이온2 조건 설정을 사용한다.

레벨 0은 목록 수신이 끝난 미보유 상태다. 연결 끊김, 통신 OFF, 목록 미수신, 잘못된 값은 모든 비교에서 실패한다. bool은 숫자로 취급하지 않는다. 레벨과 슬롯 채용 여부는 별개이므로 필요하면 쿨타임·슬롯 조건과 조합한다.

기존 조건·프로필을 유지하며 레벨 비교값과 비교 연산자를 저장한다. 실행 분석에도 초가 아닌 레벨로 표시한다.

검증: 레벨 조건 테스트 3개, 기존 아이온2 조건 9개, 실행 분석 20개, 소모품 조건 4개 통과. 기존 수정 파일은 보존했고 변경 직전 백업은 `build/skill-level-20261027`에 저장했다. 실행 중 매크로는 자동 재시작하지 않았다.
