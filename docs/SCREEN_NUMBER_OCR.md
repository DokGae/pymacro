# 화면숫자(OCR) 사용법

1. 메인 창의 **기능 → 화면숫자(OCR)**를 엽니다.
2. 이름(예: 대상거리)을 입력하고 **영역 지정**으로 게임의 숫자 한 줄을 선택합니다.
3. **저장하고 인식 테스트**를 눌러 현재 인식 숫자를 확인합니다. 창을 닫아도 인식은 계속됩니다.
4. 조건 설정에서 **화면숫자(OCR)**를 선택하고 등록 항목·비교 방식·기준값을 설정합니다.

현재 한 개의 이름 있는 OCR 영역을 등록하여 모든 조건이 공유합니다.
설정 창에서 중지한 다음 영역과 이름을 수정할 수 있습니다.
등록 이름을 바꾸면 이전 이름을 참조하는 조건도 새 이름으로 변경하세요.
인식 실패나 0.5초 이상 지난 값은 조건 불충족으로 처리합니다.
기존 OCR 거리 조건은 새 조건 화면에서 그대로 열립니다.

기존 프로필 전체를 옮기려면 OCR 관리 창 아래의 변환 버튼으로 저장된 JSON을 선택하세요.
`대상거리` 외부 조건의 출처만 바꾼 새 OCR 사본이 생성됩니다. 기존 파일은 유지됩니다.
매크로에서 생성된 사본을 불러오세요. 저장하지 않은 편집 내용은 변환 전에 먼저 저장해야 합니다.
`대상높이거리` 조건은 변환하지 않습니다.

실제 적용 시 화면의 거리 의미와 기존 패킷 거리의 의미·반올림 단위가 같은지 확인하세요.
게임 UI 배율이나 해상도를 바꾸면 영역을 다시 지정하세요.

## 인식 검증 강화
작은 숫자를 높이 48픽셀로 확대하고 명암·흑백 두 영상에서 같은 숫자가 나오는지 검사합니다. 두 프레임 연속 일치해야 조건에 사용하며 불일치·실패 때 이전 값을 유지하지 않습니다. 기본 초당 10회에서 값 변경 확인은 약 한 주기(100ms)가 추가됩니다. 검증이 늘어도 같은 오인식이 반복되는 경우는 남아 있으므로 실제 게임 화면에서 확인하세요. 영역은 최대 자릿수 전체와 약간의 여백을 포함해야 합니다.
