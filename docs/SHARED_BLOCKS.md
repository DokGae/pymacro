# 공용 블록

매크로 편집의 **병렬 작업** 옆에 **공용 블록** 탭이 있습니다. 블록은 현재 프로필 JSON 안에 저장되며 같은 파일의 모든 매크로에서 공유합니다.

탭 제목의 `(숫자)`는 파일 안의 공용 블록 개수입니다. 목록에는 `침투 · 사용 3곳`처럼 이름과 사용 횟수를 표시하고, 입력한 설명이 있으면 함께 표시합니다. 설명은 공용 원본 편집에서 추가·수정합니다. 내부 내용은 목록을 더블클릭하여 미리보기로 확인합니다. 검색 결과가 없어도 탭 개수는 파일 전체 기준을 유지합니다.

## 기존 액션 묶기

1. 같은 분기의 연속된 액션 또는 IF 전체를 선택합니다.
2. 우클릭 → **선택을 공용 블록으로 묶기**에서 이름을 입력합니다.
3. 선택한 자리가 연결된 공용 블록 한 줄로 바뀝니다. 현재 매크로에 완전히 동일한 묶음이 더 있으면 위치 목록을 자동으로 보여줍니다. 함께 변경할 위치를 체크하고 **선택한 위치를 연결로 교체**를 누르거나 **나중에 / 닫기**로 넘어갑니다.
4. 그 줄을 복사·붙여넣기하거나 **액션 추가 → 종류: 공용 블록**에서 이름을 검색하여 재사용합니다. 별도의 삽입 버튼은 없습니다.

미리보기는 자동으로 열리지 않습니다. 공용 블록 탭의 **공용 블록 미리보기** 또는 호출 줄의 우클릭 → **공용 블록 미리보기**로 열 수 있습니다. 더블클릭 또는 **공용 원본 편집**을 누르면 기존 액션 편집 방식으로 수정합니다. **미리보기 닫기** 또는 **닫기 / 돌아가기**는 원래 트리의 선택과 스크롤을 유지하며 패널을 닫습니다.

액션 트리의 순번·타입·이름·내용·활성 열은 열 제목 사이의 경계를 드래그하여 너비를 조절할 수 있습니다.

원본 변경은 현재 매크로 편집의 **확인**으로 적용하고, 프로필 저장으로 파일에 기록합니다. **취소**하면 공용 블록 변경도 취소됩니다. 생성·이름 변경·원본 수정·연결 해제는 기존 실행 취소/다시 실행에 포함됩니다. 이미 실행 중인 매크로는 시작 시점의 블록 내용을 유지하며 다음 실행부터 변경을 사용합니다.

## 관리

- **새 블록 / 복제:** 공용 원본을 만들거나 별개의 원본으로 복제합니다.
- **사용 위치:** 매크로 및 다른 공용 블록의 직접 호출 위치를 표시합니다. 다른 매크로로 이동하면 현재 편집을 확인·적용한 뒤 이동합니다. 파일 저장은 별도입니다.
- **이곳만 연결 해제:** 선택한 호출 자리에 현재 공용 원본의 액션들을 원래 순서와 구조 그대로 펼칩니다. 별도 그룹을 만들지 않습니다. 비활성 호출은 펼친 액션도 비활성으로 유지하며, 다른 호출은 원본과 계속 연결됩니다.
- **같은 내용 찾기:** 공용 블록 탭의 버튼 또는 호출 줄 우클릭 메뉴로 언제든 다시 검색할 수 있습니다. 선택한 공용 원본과 완전히 같은 묶음을 현재 매크로에서 찾아 선택한 위치만 교체합니다. 조건·타이머·분기·활성 여부 등이 다른 묶음은 교체하지 않습니다. 위치는 매크로·작업 구분과 액션 이름 경로로 표시하며, **선택한 위치 보기** 또는 더블클릭으로 실제 액션에 이동합니다.
- **삭제:** 미사용 블록만 삭제할 수 있습니다. 목록에는 사용 위치 수 또는 미사용 상태가 표시됩니다.
- **공용 조건 관리:** 기존 공용 설정 관리 화면을 엽니다. 조건만 공유하려면 IF 조건 편집의 공용 조건 연결을 사용합니다.

## 실행 규칙과 범위

호출된 자리에서 블록의 액션을 순서대로 실행합니다. IF 조건은 호출할 때마다 검사하고 각 호출 위치의 조건 확인 횟수 및 변화 감지 상태를 독립적으로 관리합니다. return / continue / break / 바깥 라벨로 goto는 호출자에게 전달됩니다. 중단 액션 및 병렬 작업 내부에서도 사용할 수 있습니다.

병렬 주기는 기존 최상위 병렬 그룹·IF에서 관리하고 그 내부 액션을 공용화합니다. 우선순위 그룹(`first_true` 계열)은 그룹 전체를 묶어야 합니다. 이동 대상 `label`은 공용 블록 바깥에 두어야 합니다. 순환 호출, 없는 원본, 잘못된 중첩 병렬 작업은 검증에서 차단합니다.

다른 프로필 파일로 호출 줄만 붙여넣어 원본이 없는 경우는 차단합니다. 파일 자체를 복사하면 정의와 호출이 함께 이동합니다. 기존 사용자 프로필은 자동 변환하지 않습니다.

## 저장 형식

`shared_blocks`는 변경되지 않는 ID를 키로 사용하며 각 정의에 `name`, `description`, `actions`를 저장합니다. 호출 액션은 `type: shared_block` 및 `block_ref`로 원본을 참조합니다. 이름을 바꿔도 연결은 유지됩니다. 실행할 때는 원본을 독립적으로 복제하므로 저장된 호출 안에 원본 액션이 중복 저장되지 않습니다.
