매크로 엔진 + PyQt6 GUI (액션 트리 / 조건 / 픽셀겟 / 라벨 점프)
============================================================

AION2 전용 스킬 단축키
--------------------
모니터의 `스킬 관리 → 퀵슬롯 단축키`에서 게임의 빠른 사용 1~12와 같은 키를 입력하고 `퀵슬롯 단축키 외부 전송`을 켭니다.
매크로 `press` 액션에서 `입력 방식 → AION2 전용 → 스킬 단축키`를 선택한 뒤 스킬을 지정합니다. 현재 연결된 키와 수신 대기 사유를 액션 설정에서 확인할 수 있습니다.
게임에서 스킬 위치를 옮기거나 모니터에서 키를 수정하면 다음 press에 반영됩니다. 기존 press의 누르는 시간·간격·반복 설정을 그대로 사용합니다.
미등록·슬롯 미수신·키 미설정·전송 OFF·통신 끊김이면 해당 액션만 건너뛰고 다음 액션을 실행합니다. 이전 수신 키나 직접 입력 키를 대신 사용하지 않습니다.
같은 스킬이 여러 칸에 있으면 빠른 사용 번호가 앞선 칸을 사용합니다. 한 칸의 여러 스킬은 같은 키를 공유하므로 키 입력 자체가 특정 스킬의 발동을 보장하지는 않습니다.
쿨타임 확인과 사용 후 대기는 기존 AION2 전용 IF 조건으로 설정합니다.

IF → AION2 전용 → `스킬 쿨타임 확인`은 액티브·스티그마 247종을 내/현재 대상으로 선택하고 사용 가능(0초), 쿨타임 중(0초 초과), 남은 시간 비교를 지원합니다.
모니터의 스킬 관리 → 직업별 아이콘 목록에서 `내 통신`·`대상 통신`을 체크한 스킬만 값을 전송합니다. 화면 표시와 전송은 독립적입니다.
기존 외부 프로그램 상태의 `내.스킬쿨.절단의맹타` 같은 변수 이름도 유지됩니다. 전송 OFF·미감지·연결 끊김은 0으로 취급하지 않습니다.

IF의 `AION2 전용 → 스킬 사용 후 대기 완료`에서 충전 스킬과 제한 시간(기본 1초)을 선택할 수 있습니다.
살성 `기습`도 선택할 수 있습니다. 충전형 특화의 실제 사용 정보를 모니터에서 받아 사용 후 대기 시간을 판정합니다.
LeeSangJinMonitor의 스킬 관리에서 충전 스킬 사용 확인 통신을 켜고 같은 프로그램 ID·포트를 사용하세요.
예: `HP < 80 AND 스킬쿨 = 0 AND 스킬 사용 후 대기 완료(쾌유의주문 / 1초)` 뒤에 press를 배치합니다.
실제 사용 확인 후 1초 미만이면 해당 조건만 거짓이며 다음 IF들은 계속 처리합니다. 키 입력 실패로 사용 패킷이 없으면 재시도를 허용합니다.
모니터가 마지막 사용부터 경과한 시간을 전송하므로 이전 번호를 저장하는 변수나 타이머 슬롯 설정은 필요 없습니다.
현재 캐릭터 감시 시작 후 아직 사용을 관측하지 않았다면 최초 시도를 허용합니다. 연결·사용 정보 미확인은 해당 조건을 거짓으로 처리합니다.
사용 확인 수신 전의 추가 입력은 취소하지 않으며, 연타 간격은 기존 press 설정을 사용합니다. 재생의 빛은 현재 충전 스킬 등록 목록에 포함되지 않습니다.

이 프로젝트는 Interception 기반 키/픽셀 매크로 엔진과 PyQt6 GUI 편집기입니다.  
모든 동작은 “액션 트리” 하나로 표현하며, 조건·반복·점프·픽셀 읽기까지 순차적으로 배치합니다. 기본/조건 탭은 없으며, 액션을 원하는 순서로 늘어놓고 드래그앤드롭으로 재배치합니다.

주요 특징
---------
- 단일 액션 트리: `press/down/up/sleep/macro_stop/if/label/goto/return/continue/break/group/while/pixel_get` 등.
- 조건: 키/픽셀, 중첩 AND/OR, on_true/on_false 브랜치. 색상/영역 변수 참조 지원(`/var`, `${var}`, `@var`).
- 픽셀겟: 화면 픽셀을 읽어 전역 color 변수에 저장 → 이후 조건에서 색상 변수로 사용.
- 흐름 제어: 라벨/점프, 그룹 모드(모두 실행, 첫 참만 실행, 첫 참 후 continue/return, 지정 횟수 반복, 무한 반복 while+break).
- 사이클 횟수: 매크로별 반복 횟수 설정(비우면 무한).
- 변수 시스템: sleep/region/color 전역 변수, 자동완성, 픽셀겟 시 새 color 변수 자동 추가 옵션.
- UI: 트리 드래그앤드롭, IF의 ELSE 브랜치는 필요할 때만 추가/제거 버튼으로 생성.
- 매크로 복제: 목록 하단 `복제` 버튼 또는 테이블 우클릭 메뉴로 선택 매크로를 전체 액션 트리/설정 그대로 복제. 기본 이름은 `원본이름 복사본`(중복 시 `... 복사본 2`), 저장 JSON에도 같은 형태로 추가됩니다.
- 글로벌 제어 핫키는 기본 제공하지 않음. 엔진 제어는 GUI에서 수행.

설치

```
uv sync
```

액션 목록의 범위 표시와 편집
--------------------------
- 매크로 편집창은 `일반 액션 / 병렬 작업 / 중단 시 실행 / 트리거 / 기본·실행 설정` 탭으로 구성됩니다. 처음에는 일반 액션을 표시합니다. 트리거 목록·입력 조합·키 차단은 트리거 탭, 이름·설명·활성·반복 횟수·앱 범위·상호작용은 기본·실행 설정 탭에서 수정합니다. 중단 시 실행은 전용 탭에서 사용 여부를 선택하고 창 높이 전체를 이용해 편집합니다.
- 기존 `순번 / 타입 / 이름 / 값 / 설명 / 활성` 열을 유지합니다. IF에는 번호와 범위선을 표시하고 IF NOT에는 부모 IF의 번호와 이름을 표시합니다. 범위선은 마지막 하위 액션에서 └ 모양으로 끝나며 별도의 `IF 끝` 안내 행은 표시하지 않습니다. 범위 표시는 실행 액션이나 저장 데이터에 추가되지 않습니다.
- IF를 선택하면 전체 범위를 강조합니다. 목록 위에는 스크롤 위치의 소속, 아래에는 선택 항목의 소속을 표시합니다. 각 IF의 `거짓 분기로 ↓` 또는 상단 버튼으로 IF NOT으로 이동하고, IF NOT의 이름을 누르면 부모 IF로 돌아갑니다.
- `이 IF만 보기`는 해당 IF와 하위 항목만 표시합니다. `전체 목록으로` 또는 Esc로 돌아갑니다. 표시 범위를 좁혀도 숨겨진 액션이 삭제되거나 실행 대상에서 제외되지는 않습니다.
- Ctrl/Shift로 여러 액션을 선택한 뒤 `이동 준비` 또는 Ctrl+X를 누르고 목적지 행을 클릭합니다. 목적지 옆의 작은 창에서 앞·뒤·참 분기 끝·거짓 분기 끝을 선택하고 이동 또는 복사를 완료합니다. 원본은 완료 전까지 점선으로 표시되어 유지되며 Esc로 취소합니다. Alt+이동 버튼 클릭은 원본을 유지한 복사이고 `복사본 넣기` 버튼도 제공합니다. IF를 선택하면 중첩 IF와 ELIF·IF NOT 하위 전체를 포함합니다.
- 드래그는 점 손잡이에서만 시작하고 행 앞뒤에 굵은 보라색 삽입선 하나를 표시합니다. 분기 안으로 자동 진입하지 않으며 분기 간 이동은 이동 준비에서 명시적으로 선택합니다. Alt(기존 Ctrl도 지원)를 누르면 복사합니다. 선택한 행은 옅은 청록 배경·짙은 청록 글자와 왼쪽 표시선으로, IF 범위는 옅은 배경으로 구분하며 하단에 선택 수와 하위 포함 총수를 표시합니다. 여러 행 선택 상태에서 활성 체크를 누르면 함께 적용합니다.
- `실행 취소 / 다시 실행` 또는 Ctrl+Z / Ctrl+Y(Ctrl+Shift+Z)로 액션 추가·수정·삭제·활성 변경·이동·복사를 복구합니다. 일반·병렬·중단 액션 및 중단 액션 사용 여부를 하나의 기록으로 관리하며 최근 100회까지 유지합니다. 편집창을 닫으면 기록은 사라집니다. 트리거·프로필·공용 설정 편집은 이 액션 기록의 대상이 아닙니다. 열린 액션·조건 편집창은 먼저 확인 또는 취소한 뒤 기록을 되돌립니다.
- 비활성 항목은 읽을 수 있는 글자색과 옅은 붉은 배경으로 표시합니다. 비활성화할 때 자동으로 접지 않습니다. 활성 체크는 깊이와 무관하게 같은 열에 정렬하고, `더 촘촘하게`로 행 간격을 조절합니다.

GUI 회귀 검사: `.venv\Scripts\python.exe -m unittest discover -s tests -v` (오프스크린 Qt, 엔진 및 실제 키 입력 미실행).

실행


공용 설정
---------
- 메인 화면 오른쪽 `이 매크로의 공용 설정`에서 현재 매크로가 사용하는 감지·조건·기존 변수를 확인합니다. 사용처는 `현재 매크로 / 프로필 전체`로 표시하며, 이름·값 검색과 전체·미사용·연결 오류 필터를 제공합니다.
- 조건 설정의 `공용으로 만들기`로 현재 검사를 등록하고 바로 연결합니다. `공용 수정`은 연결된 사용처에 함께 반영하고, `이곳만 수정`은 최신 값을 가져와 연결을 해제합니다. 픽셀의 있음·없음 판정은 각 IF에서 유지됩니다.
- 조건창에서 등록하면 매크로 편집을 완료하기 전에도 오른쪽 목록에 즉시 표시됩니다. 동일한 검사 설정이 있으면 개수와 사용처를 보여주고 `모두 연결 / 현재 조건만`을 선택합니다. 범위·색상 또는 팩·오차·대상 창이 같은 조건을 대상으로 하며, 편집창에서 취소한 연결은 저장된 매크로에 반영하지 않습니다.
- 조건 트리에서는 선택한 AND·OR 묶음도 공용화하거나 기존 공용 조건으로 교체할 수 있습니다. 연결된 조건은 요약에 `🔗` 표시가 나타납니다.
- 좌표·색상·키·시간 등의 입력칸 오른쪽 아이콘에서 기존 공용 값을 선택하거나 현재 값을 이름 붙여 등록할 수 있습니다. 기존 `/이름`, `${이름}`, `@이름` 참조도 유지됩니다.
- `더보기 → 공용화 검토`에서 현재 매크로 또는 프로필 전체의 동일 조건·조건 묶음과 기존 공용에 연결 가능한 위치를 확인합니다. `일부 설정도 찾기`를 켜면 반복 영역·색상도 표시합니다. 위치를 더블클릭하면 실제 매크로 편집창의 해당 조건을 열고, 체크한 위치만 연결합니다. 후보마다 연결 후 다시 검사하므로 겹치는 후보를 중복 적용하지 않습니다. 판정 방향과 실행 액션은 유지됩니다.
- 사용처를 더블클릭하면 실제 매크로 편집창에서 해당 액션을 선택·스크롤하고 액션 설정 → 조건 편집 → 해당 조건 설정을 이어서 엽니다. 중첩 IF, ELSE·ELIF, 병렬·종료 액션의 위치를 따라가며 확인·취소는 기존 편집 흐름을 사용합니다. 좌표·범위·색상은 `수정`에서 조건을 열어 변경하고, 기존 이미지 뷰어의 F1·범위 선택 기능을 사용합니다.
- 공용 설정은 현재 프로필의 `shared_settings`에 보존됩니다. 편집 후 프로필을 저장하고 `변경 적용`으로 실행에 반영하세요. 매크로를 다른 프로필에 복사·붙여넣을 때 필요한 공용 설정과 값을 함께 가져오며 충돌 시 기존 항목을 덮어쓰지 않습니다.
- 공용 패널의 `되돌리기`는 직전 공용 편집을 되돌립니다. 그 이후 별도 매크로 편집이 있으면 덮어쓰기를 방지하기 위해 되돌리기를 적용하지 않습니다. 누락된 연결과 순환 참조는 오류로 처리합니다.
- 목록은 Shift로 범위 선택, Ctrl/Alt로 개별 선택, Ctrl+A로 전체 선택할 수 있습니다. `삭제` 또는 Delete로 선택 항목을 한 번에 정리합니다. 사용 중인 항목과 남아 있는 설정의 의존 항목은 유지하며 삭제 작업은 한 번에 되돌릴 수 있습니다.
- 하단은 `추가 / 수정 / 삭제 / 더보기`로 정리했습니다. `더보기 → 기존 미사용 값 모두 정리`로 현재 프로필의 불필요한 예전 값들을 일괄 제거할 수 있습니다. 이름 변경·복제·테스트·중복 정리·되돌리기도 더보기에 있습니다.
- 적용 전 추가·수정 항목은 노란색, 삭제 예정 항목은 붉은색으로 표시됩니다. 삭제 예정 행은 `변경 적용` 성공 후 사라집니다. `변경 취소`로 적용 전 공용 편집을 복원할 수 있습니다. 이후 다른 매크로 편집이 있으면 이를 덮어쓰지 않도록 일괄 취소를 막습니다.
- 새 위치·영역 값을 추가하면 이미지 뷰어와 범위 선택을 바로 엽니다. 수정창에서 직접 입력하거나 이미지 뷰어의 위치(F1)·범위 선택으로 변경할 수 있습니다. 이미지가 없으면 이미지를 연 뒤 범위 선택 버튼을 누르세요.
- 빈 공용 값 목록에 `변수1`부터 `변수20`까지 자동 생성하지 않습니다. 예전 기본 슬롯 20개가 저장된 프로필을 불러올 때, 값이 0이고 설명·참조가 없는 기본 슬롯은 정리합니다. 사용 중이거나 직접 수정한 값은 유지합니다. 공용 값 추가 시 현재 목록 범위를 유지합니다.

픽셀 팩
-------
- 기능 메뉴의 `픽셀 팩 관리`에서 팩을 만들고 항목을 추가합니다. `1~N 일괄 추가`로 숫자 항목을 한 번에 만들 수 있습니다.
- 항목을 선택한 뒤 기존 이미지 뷰어에서 픽셀 위에 커서를 놓고 F1을 누르면 등록됩니다. 같은 픽셀에서 다시 F1을 누르면 해제하고, Ctrl+Z로 직전 편집을 되돌립니다.
- `항목 초기화`는 이름을 유지하고 픽셀·미리보기를 비웁니다. Ctrl+Z로 초기화도 되돌릴 수 있습니다. 메인 GUI를 최소화해도 팩 창은 이미지 뷰어 위에 유지됩니다.
- 선택한 항목의 픽셀만 뷰어에 네모로 표시됩니다. 팩 창은 뷰어보다 위에 유지됩니다. F1 등록 체크를 끄거나 창을 닫으면 기존 F1 좌표 복사로 돌아갑니다.
- 픽셀 색상·상대 배치와 미리보기 사본은 `pattern_packs.json`에 자동 저장되어 원본 이미지 삭제 후에도 유지됩니다. 다른 원본 이미지에서는 새 항목을 만들어 등록하세요.
- IF 픽셀 조건에서 `팩 이름 / 전체` 또는 `팩 이름 / 항목 이름`을 선택하면 바로 적용되고 색상 입력줄이 숨겨집니다. `선택 안 함`으로 바꾸면 색상 입력으로 돌아갑니다. 전체의 `있음`은 하나라도 발견, `없음`은 모두 미발견입니다. 개별 항목은 해당 패턴만 검사합니다. 검색 범위와 색상 오차는 해당 IF에서 설정합니다. 빈 팩은 사용할 수 없습니다.
- 별도의 픽셀 패턴 관리 기능은 팩 관리로 통합했습니다. 기존 패턴을 참조하던 조건은 팩 또는 개별 항목을 다시 선택해야 합니다. 기존 패턴 자동 이전은 하지 않습니다.

액션 타입 요약
--------------
- `press/down/up`: 키 입력.
- `sleep`: `ms`/`초`/`분`/`시` 단위, 단일값 또는 범위 `1000~1500`, `1-3`.
- `timer`: 타이머1~20 슬롯을 지정 초 값(정수/소수, 예: 0.1)으로 초기화(예: 타이머1=0). 설정 이후 실시간으로 1초씩 자동 증가.
- `computer_shutdown`: 컴퓨터 종료 명령 실행.
- `process_control`: 창 활성화/포커스, 프로그램 실행, 프로그램 종료, 프로그램 재실행을 하나의 프로그램 제어 액션에서 선택.
- `if`: 조건이 참이면 children, 거짓이면 ELSE children 실행(ELSE는 필요할 때만 추가).
- `label` / `goto`: 흐름 점프.
- `return`: 현재 매크로 종료.
- `macro_stop`: 현재 매크로를 즉시 중단(중단 액션 실행 포함).
- `continue`: 매크로 사이클 처음으로.
- `break`: 현재 그룹/while 루프 탈출.
- `group`: children 실행. 그룹 모드:
  - `all`(기본): 모두 실행
  - `first_true`: 조건 히트 시 그룹 종료
  - `first_true_continue`: 조건 히트 시 매크로 사이클 처음으로
  - `first_true_return`: 조건 히트 시 매크로 종료
  - `while`: break를 만날 때까지 children을 무한 반복(루프 내부에 sleep 넣어 조절)
  - `repeat_n`: 지정한 횟수만큼 children 실행(continue=다음 반복, break=즉시 종료)
- `pixel_get`: 좌표(x,y 또는 region 변수)에서 한 픽셀 색을 읽어 color 변수에 저장. w/h를 입력해도 1x1로 처리. 없는 변수면 추가 여부 확인.
- `noop`: 활성 off 등 자리를 유지할 때 사용.

병렬 그룹 / IF
--------------
- 매크로 편집창의 `일반 액션` 탭은 순차 실행, `병렬 작업` 탭은 독립적으로 반복하는 작업을 관리합니다. 기존에 병렬 체크한 최상위 그룹·IF는 병렬 탭에 자동으로 모아 표시하며 저장 형식은 기존과 호환됩니다.
- 병렬 탭의 `+ 병렬 그룹` 또는 `+ 병렬 IF`로 작업을 만들고 `하위 액션 추가`로 내용을 구성합니다. 최상위 항목 하나가 독립적인 병렬 작업입니다.
- 작업 또는 그 하위 액션을 선택하고 상단 `선택 작업 주기`에서 즉시 주기를 변경할 수 있습니다. 기본 1초, 0~86400초 범위의 소수 입력을 지원합니다. `0초 · 기본 속도`는 작업을 마친 뒤 일반 액션 트리와 같은 엔진 기본 반복 간격으로 계속 검사합니다. 메인 작업과 실행 시점이 동기화되는 것은 아닙니다. 활성 체크, 복사/붙여넣기, 순서 변경, 삭제도 기존 트리처럼 사용할 수 있습니다.
- 일반 탭에서 최상위 항목을 선택하고 `병렬로 이동`을 누르면 병렬 탭으로 옮깁니다. 그룹·IF는 그대로 이동하고, 키·대기 등 일반 액션은 선택 순서를 유지한 하나의 그룹으로 묶습니다. `일반으로 이동`으로 순차 실행에 되돌릴 수 있습니다.
- 일반 탭의 그룹·IF 편집에서 `병렬 실행`을 체크하는 기존 방식도 지원하며, 확인하면 병렬 탭으로 이동합니다. 병렬 작업 안에서 다른 병렬 작업의 라벨로 점프할 수 없습니다.
- 트리 값 열에 `병렬 · 1초마다`처럼 표시합니다. 병렬 항목은 메인의 순차 실행에서 건너뛰며, 매크로 시작 즉시 별도로 실행합니다. 메인이 sleep 또는 무한 반복 중이어도 동작합니다.
- 그룹 내부는 기존 순서대로 실행합니다. IF는 매 주기 조건을 다시 평가하고 참/ELIF/거짓 분기를 실행합니다. 변수와 타이머는 메인과 공유합니다.
- 주기는 실행 시작 간격입니다. 작업이 오래 걸리면 놓친 회차는 건너뛰며, 같은 항목을 겹쳐 실행하거나 밀린 실행을 몰아서 처리하지 않습니다.
- 주기마다 그룹 내용을 한 번 실행하려면 그룹 모드를 `모두 실행`으로 선택합니다. `무한 반복` 모드는 break로 끝나기 전까지 첫 실행 안에서 계속 반복하므로 주기가 내부 반복의 간격을 대신하지 않습니다.
- 매크로 종료·중지·일시중지 시 병렬 실행도 함께 멈춥니다. 병렬에서 누른 키도 해제/일시중지 유지 정책에 포함합니다. 재개 시 병렬 감시를 다시 시작합니다.
- 병렬 항목 안의 return은 해당 병렬 작업을 종료합니다. continue는 해당 반복 범위에 적용하고, break는 내부 그룹에서 처리합니다. goto는 병렬 작업 내부의 라벨만 사용할 수 있습니다. `현재 매크로 중지`는 메인과 병렬 작업을 함께 중지합니다.
- 다른 매크로 1사이클 실행으로 호출한 대상의 병렬 작업은 그 호출이 끝날 때 함께 끝납니다.
- 중첩 병렬과 중단 액션의 병렬 설정은 지원하지 않습니다. 병렬 항목 자체에는 `첫 사이클만 실행`과 `첫 입력 1회 무조건 실행`을 함께 설정할 수 없습니다.

조건
----
- 키/마우스: `press/down/up/hold/released` (mouse1~5 포함).
- 픽셀: 영역/색상/허용오차, “있을 때 참” 또는 “없을 때 참”.
- 타이머: 슬롯(1~20)과 비교값(초, 소수 가능), 비교 방식(>=, >, ==, <=, <, !=).
- 시간/날짜: `매일 시각`(`03:30`, `23:00~01:00`), `날짜`(`2026-04-23`), `날짜+시간`(`2026-04-23 03:30`) 비교 지원. `~` 범위 입력 가능.
- 색상 입력: 16진수(`ff0000`) 또는 변수(`/momo`). 변수는 런타임에 해석되며 값이 비어 있으면 조건은 실패(false).
- 영역 입력: `x,y` 또는 `x,y,w,h` (w,h를 생략하면 1x1).

변수(전역)
----------
- 종류: `sleep`, `region`, `color`.
- 참조: `/name`, `${name}`, `@name`.
- UI 탭에서 추가/수정, 입력란에서 `/`를 치면 자동완성.
- 픽셀겟에서 새 color 변수를 입력하면 추가 여부 팝업(Yes 시 기본값 000000으로 등록).

흐름 제어 예시
-------------
- “조건이 참이면 처음으로”: IF 안에 조건 + THEN에 `goto`/`label` 또는 그룹 모드 `first_true_continue`.
- “조건이 참이면 종료”: 그룹 모드 `first_true_return` 또는 THEN에 `return`.
- “N회만 실행”: 그룹 모드 `repeat_n` + 반복 횟수 지정.
- “무한 반복 루프”: 그룹 모드 `while` + 내부에 `break` 조건.

기본 예시 매크로
----------------
- 트리거 z(hold): `r` → `sleep 50` → `t` → `if(pixel) ? f1 : f2` 반복.

사용 팁
-------
- 액션 편집의 `첫 입력 1회 무조건 실행` 옵션을 켜면 홀드/토글 해제 신호와 상관없이 첫 사이클을 끝까지 실행합니다. 트리거 키와 같은 키를 눌러야 하는 매크로(예: Shift 트리거 + Shift 5회 입력)에서 초반에 끊기지 않도록 할 때 유용합니다.
- 딜레이가 필요 없는 곳엔 `sleep`을 넣지 않음. 그룹 `while` 내부는 틱 슬립 없이 최대 속도로 반복하므로 필요 시 `sleep`을 끼워 넣어 CPU 사용을 조절하세요.
- ELSE가 필요 없으면 추가하지 않아도 됩니다. 필요 시 `ELSE 추가` 버튼으로 생성, `ELSE 제거`로 삭제.

알려진 요구사항
--------------
- Windows, 관리자 권한 실행.
- Interception 드라이버 설치 필수(키 입력/차단 기능용).

특정 창에서 픽셀/패턴 인식
-------------------------
- `스크린샷 → 캡처 대상 → 특정 창 선택`에서 프로그램을 한 번 선택합니다. 기존 단일 캡처 단축키 또는 `한 장 찍기`, 연속 캡처를 그대로 사용할 수 있습니다. 선택은 재실행 후에도 유지됩니다.
- 해당 스샷을 이미지 뷰어에서 열고 기존처럼 F1(좌표), F2(색상), 범위 선택(Ctrl+F1)을 사용합니다. 열린 조건 편집창에는 대상 창과 내부 좌표가 자동으로 적용됩니다. 전체 화면 스샷에서는 화면 기준으로 자동 전환됩니다.
- 창의 제목 표시줄/테두리를 제외한 내부 영역을 기준으로 저장하므로 창을 이동해도 같은 영역을 인식합니다. 실행 파일 경로와 창 클래스로 다시 찾으며 같은 프로그램 창이 여러 개면 제목으로 구분합니다.
- 대상 창이 없거나 최소화되거나 캡처 당시와 크기가 달라졌거나 영역이 화면 밖이면 검사 불가로 표시하고 조건 결과는 거짓으로 처리합니다. `색상이 없을 때 참`도 검사 불가 상태에서는 거짓입니다.
- 현재는 화면에 보이는 창 영역을 캡처합니다. 다른 창에 가려진 부분에는 덮인 화면이 찍힙니다. 크기/배율을 바꾸면 스샷을 다시 찍어 영역을 지정하세요. 픽셀겟 액션은 기존 화면 좌표를 사용합니다.
- 이미지와 함께 저장되는 `.png.json`/`.jpg.json` 파일에 대상 창 정보가 들어 있습니다. 스샷을 다른 폴더로 옮길 때 두 파일을 함께 옮기세요.

빠른 토글
---------
- IF 또는 액션 편집에서 `빠른 토글에 표시`를 체크하고 표시 이름을 입력합니다. 이름을 비우면 액션 이름을 사용합니다. 액션 목록 우클릭에서도 등록·해제할 수 있습니다.
- 매크로 편집 내용을 반영하면 새로 등록한 항목의 토글 창이 열립니다. 닫은 창은 `기능 → 빠른 토글`에서 다시 엽니다.
- 작은 창에는 이름과 ON/OFF 스위치만 표시합니다. 실행 중 바꾸면 다음 해당 액션 실행부터 반영되며, 이미 진행 중인 액션은 끝까지 수행합니다. 부모 항목이 꺼진 경우 마우스를 올리면 확인할 수 있습니다.
- 기본 제목 표시줄 대신 작은 아이콘 헤더를 사용합니다. 제목 부분을 드래그하여 이동하고 네 모서리를 드래그하여 크기를 조절합니다. 핀 아이콘은 항상 위 표시, 노란 선은 최소화, 분홍색 X는 닫기입니다.
- 상단에는 현재 매크로 파일 이름과 작은 투명도 슬라이더를 표시합니다. 슬라이더로 배경 투명도를 0~100%로 조절하고, 수치는 마우스를 올려 확인합니다. 글자와 스위치는 선명하게 유지됩니다. 위치·크기·투명도·핀 상태는 자동 저장하고, 등록 항목·표시 이름·ON/OFF 상태는 프로필 저장에 포함합니다.
- 프로그램 종료 당시 열려 있던 토글 창은 다음 실행 때 다시 표시합니다. X 또는 Esc로 직접 닫은 창은 다시 표시하지 않습니다.
- 하단 `잠금`을 누르면 버튼 외 영역의 클릭이 뒤에 있는 게임으로 통과합니다. ON/OFF·상단 버튼·`잠금 해제`는 계속 사용할 수 있으며, 잠금 중에는 창 이동·크기 조절·투명도 조절을 막습니다. 잠금 상태도 자동 저장합니다.
- 매크로 편집기의 비활성 숨기기·열 너비·마지막 탭·창 위치와 크기를 기억합니다. 같은 프로필의 같은 매크로를 다시 열면 IF 접기·펼치기·집중 보기·선택 행·스크롤 위치도 복원합니다. 이 화면 설정은 편집 내용의 확인·취소와 별도로 저장합니다.

IF 조건의 외부 프로그램 상태 (TCP)에서 프로그램 ID, 포트, 내용 이름을 정해 수신값을 비교합니다.
작은 모니터 기본값: ID leesangjin-monitor / 포트 47653 / 내용 내효과.123 또는 대상효과.123.
TCP 소켓 상태 통신을 지원하는 프로그램에 사용할 수 있으며, 다른 프로그램 ID와 항목도 직접 입력할 수 있습니다.
프로필을 불러오면 자동 연결하고, 상대를 다시 켜면 자동 재연결합니다.
연결 끊김·감지 대기·미수신은 해당 조건을 거짓으로 처리합니다. AND/OR의 다른 조건은 정상적으로 계산하고 거짓 분기·ELIF·ELSE도 기존 순서대로 실행합니다. 미수신 값을 숫자 0이나 수신된 false로 대체하지 않으므로 `같지 않음`이나 `꺼짐` 조건도 미수신이면 거짓입니다.
기존 이미지/픽셀 조건은 함께 사용할 수 있습니다. 프로토콜과 사용법은 TCP_STATE_PROTOCOL.md를 참고하세요.

실행 분석
---------
- `기능 → 실행 분석`을 열고 `시작`을 누른 시점부터 측정합니다. 창을 열기만 하면 측정하지 않습니다. 실행 중인 매크로도 시작 이후 발생한 이벤트부터 집계합니다.
- `멈춤`은 측정만 중단하고 결과를 화면에 유지합니다. 매크로는 계속 실행됩니다. `시작`을 다시 누르면 이전 결과를 지우고 새로 측정합니다.
- 현재 측정 하나만 유지합니다. 창을 닫거나 Esc로 나가면 측정과 결과를 지웁니다. 파일 저장·과거 실행 목록·상세 경로 로그는 만들지 않습니다.
- 측정 중 실제 실행된 매크로만 표시하고, 같은 매크로의 반복 실행과 병렬 작업은 해당 액션별 횟수로 합산합니다. 여러 매크로의 결과는 매크로별로 구분합니다. 반복마다 기록을 추가하지 않아 데이터 크기는 주로 실행된 매크로의 액션 수에 따라 정해집니다.
- 표에는 `순번 / 액션 / 도달 / 조건 참·거짓 / 입력 / 상태`를 표시합니다. 순번은 편집기의 기본·병렬·중단 액션 목록과 각각 동일하며 IF NOT 행은 `↳`로 표시합니다. 순번과 결과 열은 가운데 정렬합니다. IF·액션을 선택하면 하단에 설명과 마지막 상태를 표시합니다. 외부값 미수신은 거짓 횟수에 포함하며 상세에 미수신 사유를 표시합니다. 라벨 이동 액션은 선택했을 때 이동 횟수와 도착 라벨을 설명합니다.
- IF·ELIF를 선택한 뒤 하단 `조건 상세보기`를 누르면 마지막 실제 검사의 조건별 참·거짓·미검사·비활성·검사 불가·오류를 확인할 수 있습니다. 검사 당시 값과 기준, AND·OR의 단축 검사, 참/거짓 후속 분기에 따른 최종 결과를 표시합니다. 상세보기를 열 때 재검사하지 않습니다. IF별 마지막 상세 한 개만 덮어쓰며 이미지·좌표 배열이나 상세 이력은 보관하지 않습니다. 측정하지 않을 때는 상세 정보를 수집하지 않습니다.
- `항상 위`로 다른 창 위에 표시할 수 있습니다. 화면은 0.5초마다 갱신하고 선택 행·접기 상태·스크롤 위치를 유지합니다. 이름·키 검색과 비활성 숨기기를 사용할 수 있습니다.
- 측정 중 매크로 설정을 변경하거나 빠른 토글을 바꾸면 측정을 멈추고 다시 시작하도록 안내합니다. 입력 전송 횟수는 게임 내 스킬 발동 횟수와 다릅니다.
